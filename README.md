# AvitoParser — Парсер объявлений Avito → TSV

Проект скачивает поисковые страницы Avito, парсит данные объявлений и сохраняет их в TSV-файл (разделитель — табуляция).

## Требования

- **Python 3.10+**
- **pip** (менеджер пакетов)

> Docker **не требуется**. Проект запускается напрямую.

## Установка

```bash
# 1. Клонируйте репозиторий
git clone <репозиторий>
cd AvitoParser

# 2. Создайте виртуальное окружение (рекомендуется)
python3 -m venv .venv
source .venv/bin/activate   # Linux/Mac
# .venv\Scripts\activate    # Windows

# 3. Установите зависимости
pip install -r requirements.txt
```

## Настройка

### 1. Скопируйте `.env.example` в `.env`

```bash
cp .env.example .env
```

### 2. Заполните `.env`

```env
# URL поисковой страницы Avito
AVITO_SEARCH_URL=https://www.avito.ru/moskva_i_mo/kvartiry/prodam-ASgBAgICAUSSA8YQ

# Максимальное количество страниц (0 = все)
AVITO_MAX_PAGES=0

# Путь к файлу с куками (опционально)
AVITO_COOKIES_FILE=cookies.json

# Строка кук напрямую (опционально)
AVITO_COOKIE=

# Прокси (опционально, формат: http://user:pass@host:port)
AVITO_PROXY=
```

### 3. Подготовьте куки (опционально, но рекомендуется)

Без кук Avito может показывать капчу. Экспортируйте ([описание](docs/cookies_export/COOKIES_EXPORT.md)) куки из браузера в файл `cookies.json`:

```json
{
  "cookieManagerVersion": "v2",
  "userAgent": "Mozilla/5.0 ...",
  "cookies": [
    {
      "name": "avito_session",
      "value": "...",
      "domain": ".avito.ru"
    }
  ]
}
```

## Использование

### Запуск через `parse.sh`

```bash
# С аргументом (URL поиска)
./parse.sh "https://www.avito.ru/moskva/kvartiry/prodam"

# Без аргумента (использует AVITO_SEARCH_URL из .env)
./parse.sh
```

### Запуск напрямую

```bash
python3 run_avito.py "https://www.avito.ru/moskva/kvartiry/prodam"
```

### Как получить URL поиска

1. Откройте [avito.ru](https://www.avito.ru/)
2. Выберите категорию (например, **Недвижимость → Квартиры → Купить**)
3. Настройте фильтры (город, цена, площадь, этаж и т.д.)
4. Скопируйте полный URL из адресной строки браузера

### Примеры

```bash
# Квартиры в Москве и МО
./parse.sh "https://www.avito.ru/moskva_i_mo/kvartiry/prodam-ASgBAgICAUSSA8YQ"

# Квартиры в Казани
./parse.sh "https://www.avito.ru/kazan/kvartiry/prodam-ASgBAgICAUSSA8YQ"
```

## Что парсится

Для каждого объявления извлекаются:

| Поле | Описание |
|------|----------|
| ID объявления | Номер из URL / страницы |
| URL | Полная ссылка на объявление |
| Заголовок | `h1[data-marker="item-view/title-info"]` |
| Цена | Числовое значение |
| Цена за м² | Из блока цены |
| Адрес | Полный адрес |
| Метро | `"Станция:время, Станция:время, ..."` |
| Описание | Текст объявления |
| Дата публикации | Дата размещения |
| Всего просмотров | Общее число |
| Просмотров сегодня | За сегодня |
| Имя продавца | Из блока продавца |
| Статус продавца | Частное лицо / Агентство |
| Характеристики квартиры | Комнаты, площадь, этаж, балкон, ремонт, санузел (JSON) |
| Характеристики дома | Тип, этажность, лифты, парковка (JSON) |
| Росреестр | Данные проверки (собственники, обременения) |
| Дата парсинга | Когда была обработана страница |

## Результат

TSV-файл сохраняется в папку `output/`:

```
output/
└── avito_listings.csv
```

Файл использует разделитель — табуляцию (`\t`). Открывается в Excel, Google Sheets, LibreOffice Calc (при импорте укажите разделитель Tab).

Каждый новый запуск **дозаписывает** строки в существующий файл. Чтобы начать заново — удалите `output/avito_listings.csv`.

## Как это работает

### Алгоритм

1. Загружается поисковая страница Avito (сохраняется в `Pages/`)
2. Из HTML извлекаются ссылки на объявления (`a[data-marker="item-title"]`)
3. По очереди скачивается каждое объявление
4. BeautifulSoup парсит DOM-дерево — извлекаются все поля по `data-marker` атрибутам
5. Данные записываются в TSV
6. Страница объявления удаляется
7. Определяется ссылка на следующую страницу через пагинацию
8. Цикл повторяется с шага 1

### Пагинация

Парсер ищет ссылку на следующую страницу в порядке приоритета:
- `a[data-marker="pagination-button/nextPage"]`
- `a[rel="next"]`
- aria-label со словами «Следующая» / «Next»
- Числовые ссылки `data-marker="pagination-button/page(N)"`
- Конструирование URL с параметром `p=`

### Паузы между запросами

- 3–6 секунд между объявлениями (случайная задержка)
- 3 секунды между страницами поиска

### Временные файлы

HTML-страницы сохраняются в `Pages/`:
- `search_page_0001.html`, `search_page_0002.html` — поисковые страницы (не удаляются, можно анализировать)
- `ad_*.html` — страницы объявлений (удаляются сразу после парсинга)

## Возможные проблемы

### Капча / блокировка
Avito может показывать капчу. Решения:
- Добавьте куки из браузера в `cookies.json`
- Используйте прокси (`AVITO_PROXY` в `.env`)
- Подождите и попробуйте позже

### Не найдены объявления
Если парсер не находит объявления — Avito мог изменить вёрстку. Проверьте HTML в `Pages/search_page_0001.html`. Возможно, нужно обновить CSS-селекторы в `parsers/avito_csv.py`.

### Пустые названия метро
Если метро есть, но имена пустые — проверьте HTML страницы объявления. Селектор: `span._22d8cf68e753a9b9` (контейнер метро), внутри второй `span` (название), `span._975960bc91729d0a` (время).
