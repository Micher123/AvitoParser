# House-Research — Парсер объявлений Avito → CSV

Проект скачивает поисковые страницы Avito, извлекает данные всех объявлений и сохраняет их в CSV-файл с разделителем `;`.

## Требования

- **Deno 2+** — [установка](https://deno.com)
- **curl** — обычно уже есть в системе. Если нет: `sudo apt install curl`

> Docker **не требуется**. Проект запускается напрямую через Deno.

## Установка и первый запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/zxcloli666/House-Research.git
cd House-Research

# 2. Deno сам скачает зависимости при первом запуске.
#    Ничего дополнительно устанавливать не нужно.
```

## Использование

```bash
# Формат команды:
deno task parse "<URL поисковой страницы Avito>"

# или альтернативная команда:
deno task parse-avito "<URL поисковой страницы Avito>"
```

### Как получить URL поиска

1. Откройте [avito.ru](https://www.avito.ru/)
2. Выберите категорию (например, **Недвижимость → Квартиры → Купить**)
3. Настройте нужные фильтры (город, цена, площадь, этаж и т.д.)
4. Скопируйте полный URL из адресной строки браузера
5. Передайте его в команду

### Пример

```bash
# Поиск квартир на продажу в Москве и МО
deno task parse "https://www.avito.ru/moskva_i_mo/kvartiry/prodam-ASgBAgICAUSSA8YQ"

# Поиск квартир на продажу в Казани
deno task parse "https://www.avito.ru/kazan/kvartiry/prodam-ASgBAgICAUSSA8YQ"
```

### Что произойдёт при запуске

1. Парсер скачает первую поисковую страницу Avito
2. Извлечёт ссылки на все объявления из JSON-LD (встроенные структурированные данные)
3. По очереди скачает каждое объявление и извлечёт все доступные поля:
   - заголовок, цена, цена за м², описание, адрес
   - параметры квартиры (комнаты, площадь, этаж, балкон, ремонт, мебель…)
   - параметры дома (тип, год постройки, лифты, парковка…)
   - информация о продавце (имя, тип, контакты, ID, ссылка)
   - статус объявления (активно, в избранном), телефон, мессенджеры
   - ипотека, условия сделки
   - дата размещения, просмотры (всего / сегодня)
   - изображения, геоданные, онлайн-показ
   - хлебные крошки, SEO-теги, преимущества, застройщик
4. Сохранит всё в CSV-файл
5. Перейдёт на следующую страницу поиска по пагинации и повторит шаги 1–4
6. Когда страницы закончатся — программа завершится

### Результат

CSV-файл сохраняется в папку `output/`:

```
output/
└── avito_listings.csv
```

Файл использует разделитель `;` (точка с запятой). Открывается в Excel, Google Sheets, LibreOffice Calc.

### Временные файлы

Во время работы парсер сохраняет HTML-страницы в папку `Pages/` и удаляет их сразу после обработки. После завершения работы папка будет пуста (или содержать только страницу, на которой не нашлось объявлений — её можно удалить вручную).

## Как это работает (внутреннее устройство)

### Источники данных

Парсер использует три уровня извлечения данных из HTML страницы объявления:

1. **`__staticRouterHydrationData`** — новый формат Avito (React Router). Содержит наиболее полные данные в JSON.
2. **`__initialData__`** — старый формат Avito. Используется как fallback.
3. **DOM** — direct HTML парсинг (`data-marker` атрибуты, `<meta>` теги, `itemprop`). Используется когда оба JSON-источника недоступны.

### Пагинация

Парсер автоматически определяет номер текущей страницы и находит ссылку на следующую через `data-marker="pagination-button/page(N)"`. Обработка продолжается пока есть страницы.

### Анти-блокировка

- Используется curl (более устойчив к блокировкам чем fetch)
- Случайные задержки 3–6 секунд между объявлениями
- Задержка 2.5 секунды между поисковыми страницами
- User-Agent заголовки маскируются под обычный браузер

## Возможные проблемы

### "Объявлений не найдено"
Если Avito изменил формат JSON-LD или страница вернулась пустой — проверьте отладочный HTML в папке `Pages/`.

### "curl не сработал"
Парсер автоматически переключится на встроенный `fetch()`. Если и это не поможет — возможно, Avito блокирует запросы. Попробуйте:
- Подождать и запустить позже
- Использовать VPN
- Добавить куки в заголовки (редактировать `DEFAULT_USER_AGENT` и заголовки в `downloadToFile()`)

### Как добавить куки Avito (если нужно)

Если Avito требует авторизацию, отредактируйте функцию `downloadToFile()` в `src/parsers/avito-csv.ts` — добавьте заголовок `Cookie`:

```typescript
"-H", "Cookie: ваш_куки_из_браузера",
```
