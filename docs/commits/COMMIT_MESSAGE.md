# Правила написания сообщений к коммитам

## Написание коммитов должно сопровождаться флагами, указывающими на то, что было сделано в конкретном коммите. Формат следующий:
``` bash
    <type>[optional scope]: <description>
```

## Таблица флагов (type):
| Флаг     | Описание |
|----------|----------|
|`fix`|Исправление ошибок|
|`feat`|Новый функционал|
|`build`|Изменения, связанные со сборкой/запуском проекта|
|`ci`|Изменения, связанные с CI/CD|
|`docs`|Изменения в документации|
|`style`|Форматирование кода|
|`refactor`|Рефакторинг (без исправления багов или новых фич)|
|`perf`|Оптимизация кода|
|`test`|Изменения, связанные с тестами|

## Примеры коммитов
```bash
    git commit -m "fix(avito): Исправил неправильную запись данных в файл csv."
    git commit -m "feat(cian): Реализовал парсинг данных с сайта Циан."
    git commit -m "docs: Добавил описание установки расширений для браузера."
```
